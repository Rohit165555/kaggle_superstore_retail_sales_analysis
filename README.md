# kaggle_superstore_retail_sales_analysis
End-to-end Superstore Sales Analysis using Excel, SQL, Python, SQLite, and Power BI. The project includes data cleaning, Pivot Tables, Excel dashboard creation, SQL-based business analysis, and an interactive Power BI dashboard to identify sales trends, customer behavior, profitability, and actionable business insights.

# 📊 Superstore Sales Analysis

## 📌 Project Overview

This project analyzes the Superstore sales dataset using Excel, SQL, and Power BI to uncover valuable business insights related to sales performance, profitability, customer behavior, and regional trends.

The project demonstrates the complete data analytics workflow, starting from data cleaning in Excel, business analysis using SQL, and interactive dashboard development in Power BI.

---

# 🎯 Project Objective

The primary objective of this project is to analyze Superstore sales data and identify key business insights that help improve decision-making.

The analysis focuses on:

- Sales performance
- Profitability
- Customer purchasing behavior
- Regional performance
- Product category analysis
- Shipping trends
- Business recommendations

---

**Dataset:** Kaggle Superstore Dataset
